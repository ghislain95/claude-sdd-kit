# `.sdd/harness.yaml` — review harness configuration

One file per project, versioned, generated by `sdd-init` and edited by hand afterwards. It belongs to
the gate machinery: a pull request that changes it opens the irreversible gate.

```yaml
budget:
  minutes: 90            # wall-clock time for the whole harness run on one change
  agent_runs: 24         # angle agents + verifiers + developer hand-backs; the token budget
  effort: high           # highest effort an agent of the harness may use (normal | high)
  heavy_builds: 1        # heavy builds (full test suite, mutation, bundle) running at once
  bug_hunt_level: medium # level passed to /code-review (low | medium | high)
  rounds: 3              # fix-loop rounds before escalating to the owner

angles:                  # conditional angles and the diff paths that select them
  security:      ["**/auth/**", "**/security/**", "**/*.sql", "**/migration/**", "**/*Controller*", "package*.json", "pom.xml"]
  performance:   ["src/**"]
  interface:     ["**/*.tsx", "**/*.css", "**/i18n/**"]
  sourced-claims: ["**/*.md", "CHANGELOG*"]

mechanical:              # commands each angle runs; omit a key when the tooling is absent
  conventions:
    - "./mvnw -q test -Dtest=ArchitectureTest"
    - "npm run lint"
  tests:
    run: "npm test"
    mutation: null       # e.g. "npx stryker run --mutate {files}"; null = absent, reviewed by hand
  security:
    - "npm audit --omit=dev --audit-level=high"
  performance:
    - name: "main bundle"
      command: "npm run build && du -k dist/assets/index-*.js"
      threshold: "500 kB"
  interface: []
```

Defaults when the file is missing: the budget above, no conditional angle selected except
`sourced-claims` on Markdown files, no mechanical command. The report says the defaults were used.

`{files}` in a command is replaced with the changed files of the relevant module. Paths in `angles`
are globs matched against the diff's file list.
